# 試用版ランチャー操作仕様

Owner: #6。上位 #1、公開試用版 #10。R3全機能の完成を意味しない。

- スマートフォンは4列の角丸アプリアイコン＋名称。横幅の広い環境では列数を増やす。通常タップで従来の埋込起動、右下のホームボタンで復帰。
- アイコンは対象アプリの公開済みmanifest/faviconの実ファイルを優先し、取得失敗・未設定はアプリ別の代替記号。試用版の固定候補のみ。正式な自動アイコン収集はR2の契約で扱う。
- 右クリック、タッチ長押し（500ms、10px超の移動で解除）、Shift+F10/ContextMenuキーで対象メニュー。長押し後のタップ起動を抑止、外側・キャンセル・Escapeで閉じ、フォーカスを戻す。
- メニューは開く、共有、ブラウザで開く、キャンセル。共有先はアプリ自身の公開URL。ネイティブ共有APIを優先、利用不可/失敗時はクリップボード、拒否時は選択可能なURL。ユーザーによる共有キャンセルは失敗扱いにしない。
- 任意URLの受入、既存iframeの権限変更、外部アプリの保存互換性保証は含まない。
- 共通化: Site Kitのsharing/touch actionは現時点で受入済みモジュールがなく、既存actionsはmodifier英数字shortcut契約で異なる。試用版はnative dialog/pointer/Web Shareを使う局所adapter。R2/R3正式移行時に共有ownerの実装を照合し、利用可能な場合は移行する。既存repoを一括改修しない。
