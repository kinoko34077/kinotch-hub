# 試用版ランチャー操作仕様

Owner: #6。上位 #1、公開試用版 #10。R3全機能の完成を意味しない。

- スマートフォンは4列の角丸アプリアイコン＋名称。横幅の広い環境では列数を増やす。通常タップで共通の埋込起動（個別許可なし）、端の取っ手からホームボタンを展開して復帰。
- アイコンは対象アプリの公開済みmanifest/faviconの実ファイルを優先し、取得失敗・未設定はアプリ別の代替記号。カタログの公開アイコンを使用する。
- 右クリック、タッチ長押し（500ms、10px超の移動で解除）、Shift+F10/ContextMenuキーで対象メニュー。長押し後のタップ起動を抑止、外側・キャンセル・Escapeで閉じ、フォーカスを戻す。
- メニューは開く、共有、ブラウザで開く、キャンセル。共有先はアプリ自身の公開URL。ネイティブ共有APIを優先、利用不可/失敗時はクリップボード、拒否時は選択可能なURL。ユーザーによる共有キャンセルは失敗扱いにしない。
- 短押しはメニューに転送しない。起動画面には折畳み式のホーム復帰のみ。再読込・直リンク常設を撤去。技術的非対応時はホームの既存操作メニューから明示的にブラウザ起動。通常一覧から開発fixtureを除外（#fixtureの診断用のみ）。既存sandbox権限は変更せず、外部アプリ保存互換性は実サイト検証で扱う。
- 共通化: Site Kitのsharing/touch actionは現時点で受入済みモジュールがなく、既存actionsはmodifier英数字shortcut契約で異なる。試用版はnative dialog/pointer/Web Shareを使う局所adapter。R2/R3正式移行時に共有ownerの実装を照合し、利用可能な場合は移行する。既存repoを一括改修しない。

- カタログ更新時、同一ID・URLのアプリ操作を継続する。表示差分がなければアイコンDOMを維持し、同一URLの選択・メニュー・フォーカス、実行中iframeを置換しない。対象の削除・URL変更は旧対象の新規起動を無効化し、該当メニューを閉じる。実行中の画面は勝手に再起動しない。ホーム復帰後の任意アプリ状態保持は別検証（隠れた音声・処理の問題）。

- 端の取っ手は通常折畳み、内向き横スライド/タップで展開、外向き横スライド/再タップで折畳み。上下ドラッグで位置変更、画面幅の55%を超す内向きドラッグで反対端へ移動（初期の調整可能な実装値）。取っ手のみpointer capture、iframe全面overlayなし。キーボードでは取っ手をEnter/Spaceで開閉、左右矢印で端切替、Escapeでホーム復帰。折畳み/移動はiframeを再生成しない。HermitのFrameless Modeの端操作を参照（https://hermit.chimbori.com/features/frameless ）。iOS実機のOSジェスチャーとの競合は別途確認。
